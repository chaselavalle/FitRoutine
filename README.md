**FitRoutine**

**Team Members:**
- Chase LaValle
- John Leicht

**Project Abstract:**
FitRoutine is a fitness app that allows a user to plan and manage their fitness routine. A user will be able to input personal information, select a fitness difficulty level, and select the fitness activities they would like to do weekly. FitRoutine will then email the user on a daily basis their fitness plan for the day. The app will also store data on a user’s fitness activities and basic fitness data (number of activities performed, estimated calories burned, etc.). FitRoutine aims to simplify a fitness routine and provide the user with a method of tracking their fitness progress.
